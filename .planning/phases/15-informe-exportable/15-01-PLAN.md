**1a. Print-safe layout (new finding, not in RESEARCH.md — verified by reading `app/(dashboard)/layout.tsx` and `components/dashboard/sidebar.tsx` directly in this planning session):**

Both existing `@media print` precedents (`clientes/[id]/informe`, `cadenas-comerciales/[id]/compliance`) live inside the `(dashboard)` route group, which wraps every page in `<Sidebar />` (a `fixed inset-y-0 left-0` `<aside>`, `components/dashboard/sidebar.tsx:190-194`) + a `<main>` with `pl-14`/`pl-60` padding (`app/(dashboard)/layout.tsx:38-46`). Neither the sidebar nor the padding has ever been tested against an actual print — there is no `print:hidden` on the `<aside>` anywhere in the codebase today. Without this fix, both informes built in this phase would print with the full nav sidebar overlapping the report.

- In `components/dashboard/sidebar.tsx`, add `"print:hidden"` to the `<aside>`'s `className` string at line ~191-194 (the `cn(...)` call starting `"group/sidebar fixed inset-y-0 left-0 z-30 flex flex-col transition-[width] duration-200 ease-in-out"`). Result: the sidebar is present on screen exactly as before, but `display: none` under `@media print`.
- In `app/(dashboard)/layout.tsx`, add `"print:pl-0"` as a static (unconditional) class to the `<main>` element's `cn(...)` call (currently `"flex min-h-screen flex-col overflow-auto transition-[padding-left] duration-200 ease-in-out bg-dot-grid"`, followed by the conditional `collapsed ? "pl-14" : "pl-60"`). `print:pl-0` overrides the reserved sidebar padding only inside print media — screen behavior is unchanged.

This fix benefits the 2 new informe routes (Plan 15-02/15-03) AND retroactively fixes the same latent gap in the 2 existing precedents — acceptable side effect, do not scope-creep beyond these 2 one-line additions.

- In `lib/formato-fecha.ts`: add a new exported function `formatTimestampCorto(iso: string | null): string | null` with the exact same logic as the local `formatTimestamp` (guard `if (!iso) return null` at the top, matching the existing `formatFechaCorta` null-guard style). Reuse language from the existing header comment on `formatFechaCorta` (lines 1-14) which already explains the date-only vs. timestamptz distinction — don't repeat that full explanation twice, a short "see formatFechaCorta above for date-only fields" pointer is enough.

import { formatFechaCorta } from "@/lib/formato-fecha"
import { TIPO_PROPIEDAD_LABEL, type OperacionMercadoLocal, type TipoPropiedadComercial } from "@/lib/scrapers/mercado-locales-common"
import type { BandasMercadoLocal } from "@/lib/mercado-locales-server"

  comuna: string
  operacion: OperacionMercadoLocal
  tipoPropiedad: TipoPropiedadComercial
  bandas: BandasMercadoLocal | null

  fuentes: FuenteMetodologia[]

export function MetodologiaInforme({ fuentes }: MetodologiaInformeProps) {
  return (
    <section className="mt-8 border-t border-line-fine pt-6 text-sm">
      <h2 className="text-xs font-semibold uppercase tracking-widest text-muted-foreground">Metodología y fuentes</h2>
      <p className="mt-2 text-muted-foreground">
        Datos de PortalInmobiliario recolectados por el motor de mercado de PermisoHub. Bandas de precio (P25/mediana/P75)
        recalculadas diariamente por comuna, tipo de propiedad y operación sobre listados activos.
      </p>
      <ul className="mt-3 space-y-2">
        {fuentes.map((f, i) => (
          <li key={`${f.comuna}-${f.operacion}-${f.tipoPropiedad}-${i}`}>
            {f.bandas ? (
              <>
                <span className="font-medium text-foreground">{f.comuna}</span>
                {" "}({TIPO_PROPIEDAD_LABEL[f.tipoPropiedad].singular}, {f.operacion === "venta" ? "venta" : "arriendo"}):
                {" "}muestra n={f.bandas.muestraN}

                {", "}banda vigente al {formatFechaCorta(f.bandas.statsDate)}
              </>
            ) : (
              <span className="text-amber-700">
                {f.comuna}: sin banda de mercado disponible para esta combinación — sin comparación de cohorte.
              </span>
            )}
          </li>
        ))}
      </ul>
    </section>
  )
}
