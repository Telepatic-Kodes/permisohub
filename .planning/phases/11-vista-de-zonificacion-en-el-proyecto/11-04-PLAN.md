<task type="auto">
  <name>Task 2: ZonificacionMapa component</name>
  <files>components/proyecto/zonificacion-mapa.tsx</files>
  <action>
Create `components/proyecto/zonificacion-mapa.tsx` as a `"use client"` component. Key design decisions, all deliberate:

1. **No internal data fetching** — receives `lat`, `lng`, `geometria` as props (the parent, Plan 11-07's `ZonificacionCard`, owns the fetch to `GET /api/proyectos/[id]/zonificacion`). This keeps this component's own tests/verification independent of any API route.
2. **Dynamic `import('leaflet')` inside `useEffect`**, not a top-level `import` — Leaflet references `window`/`document` at module load time, which breaks Next.js SSR if imported at the module level of a component that could ever be server-rendered first.
3. **Custom `L.divIcon` marker, NOT Leaflet's default PNG marker icon** — Leaflet's default icon path (`marker-icon.png` etc.) is a well-known breakage point under bundlers (the icon 404s unless manually re-pathed via a CDN or asset import, both of which add either an external CSP host or brittle bundler-specific asset-import typing). A small inline-SVG-via-`divIcon` sidesteps this class of bug entirely — zero extra assets, zero extra CSP surface.
4. **Graceful degrade when `geometria` is null** (Pitfall 2 from `11-RESEARCH.md`) — legacy cache rows from before this phase's `returnGeometry=true` change have no polygon. Show the marker alone with a small explanatory note, never an error.
5. **Graceful degrade when `lat`/`lng` are null** — a project whose geocoding never succeeded (or hasn't run yet) has no point either; show a placeholder message, don't attempt to mount Leaflet.

```tsx
"use client"

import { useEffect, useRef } from "react"
import "leaflet/dist/leaflet.css"
import type { Map as LeafletMap } from "leaflet"

export interface ZonaPolygon {
  type: "Polygon"
  coordinates: number[][][]
}

interface ZonificacionMapaProps {
  lat: number | null
  lng: number | null
  geometria: ZonaPolygon | null
  className?: string
}

export function ZonificacionMapa({ lat, lng, geometria, className }: ZonificacionMapaProps) {
  const containerRef = useRef<HTMLDivElement>(null)
  const mapRef = useRef<LeafletMap | null>(null)

  useEffect(() => {
    if (!containerRef.current || lat == null || lng == null) return
    let cancelled = false

    void import("leaflet").then((L) => {
      if (cancelled || !containerRef.current) return

      const map = L.map(containerRef.current).setView([lat, lng], 17)
      mapRef.current = map

      L.tileLayer("https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png", {
        attribution: '&copy; <a href="https://www.openstreetmap.org/copyright">OpenStreetMap</a>',
        maxZoom: 19,
      }).addTo(map)

      const markerIcon = L.divIcon({
        className: "",
        html: '<div style="width:14px;height:14px;border-radius:50%;background:#2563eb;border:2px solid white;box-shadow:0 0 0 1px rgba(0,0,0,.35)"></div>',
        iconSize: [14, 14],
        iconAnchor: [7, 7],
      })
      L.marker([lat, lng], { icon: markerIcon }).addTo(map)

      if (geometria) {
        const layer = L.geoJSON(geometria as GeoJSON.Geometry, {
          style: { color: "#2563eb", weight: 2, fillOpacity: 0.12 },
        }).addTo(map)
        const bounds = layer.getBounds()
        if (bounds.isValid()) map.fitBounds(bounds, { padding: [16, 16] })
      }
    })

    return () => {
      cancelled = true
      mapRef.current?.remove()
      mapRef.current = null
    }
  }, [lat, lng, geometria])

  if (lat == null || lng == null) {
    return (
      <div className={className}>
        <p className="text-xs text-muted-foreground">Sin coordenadas geocodificadas todavía.</p>
      </div>
    )
  }

  return (
    <div className={className}>
      <div ref={containerRef} className="h-[240px] w-full rounded-lg border border-border" />
      {!geometria && (
        <p className="mt-1.5 text-xs text-muted-foreground">
          Límite de zona no disponible aún — usa &quot;Actualizar&quot; para obtenerlo.
        </p>
      )}
    </div>
  )
}
```

The `<div ref={containerRef}>` MUST have an explicit height (`h-[240px]` here) — Leaflet silently renders a blank/collapsed map if its container has no computed height, a common and easy-to-miss mistake distinct from the CSP blank-tile failure mode.
